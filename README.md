# 见岸 · 心理陪伴与强迫症知识支持（H5 与数字人演示）

见岸是一款可通过手机浏览器访问的 H5 演示作品，将文本对话、心理自助入口与星云数字人展示结合。用于心理陪伴和知识支持，不提供医疗诊断，也不替代专业治疗或紧急援助。

## 快速体验

**[点击打开见岸在线演示](https://jianan-care.app.workbuddy.host/)**

[下载源码发布包](https://github.com/EthanSynn/jianan-care-demo/releases/latest) · [运行与部署说明](部署说明.md)

在线演示为已有公网部署，仓库包含后续优化，当前两者可能存在版本差异。

进入首页 → 点击对话 → 选择角色 → 发送文字。点击「连接数字人」进入数字人全屏界面，顶部「返回聊天」回到文本对话。

- 见岸：温柔陪伴，帮助梳理困扰。
- 安心：讲解心理与强迫症相关机制、循证知识。
- 小暖：倾听、日常情绪陪伴。

## 本地运行

1. 安装 Node.js 18 或以上版本。服务仅使用 Node 内置模块，无需安装第三方 npm 依赖。
2. 将根目录 `.env.example` 复制为 `.env`，填写所需配置。
3. 在根目录运行 `npm start` 或双击「启动见岸.bat」。
4. 打开 http://localhost:3000/ 。不能直接双击 HTML 代替启动服务。

模型配置：填写 `DEEPSEEK_API_KEY`，以及实际使用的 `DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL`。也支持现有代码提供的 AIPING 配置和页面 AI 设置，具体以服务实现为准。

数字人配置：

| 角色 | App ID 环境变量 | Secret 环境变量 |
|---|---|---|
| 见岸 | XINGYUN_APP_ID | XINGYUN_APP_SECRET |
| 小暖 | XINGYUN_XIAONUAN_APP_ID | XINGYUN_XIAONUAN_APP_SECRET |
| 安心 | XINGYUN_ANXIN_APP_ID | XINGYUN_ANXIN_APP_SECRET |

本包不含真实服务密钥。评委无需配置即可查看页面；真实模型对话和云端数字人需要服务凭证、可用额度与网络。数字人未配置时使用静态形象与浏览器语音降级；模型未配置时不会伪造模型回复。若比赛要求评委独立复现全部功能，应按比赛提供的保密配置渠道交付测试凭证。

本地端口冲突时，在 PowerShell 运行 `$env:PORT=3001; npm start`，访问对应端口。公网使用 HTTPS；部署到新域名时，需要设置 `XINGYUN_ALLOWED_ORIGINS` 环境变量为站点的完整 HTTPS 来源，当前保留既有部署与 localhost 配置。

## 代码结构

- `server.js`、`env-loader.js`：同源 HTTP 服务、环境变量与模型接口。
- `lib/`：安全分诊、强迫症路由、知识片段、提示词、情绪信号与数字人服务网关。
- `public/index.html`：手机界面、流式聊天、本地记录与自助页面。
- `public/avatar.js`：数字人初始化、播报、打断、销毁与降级。
- `public/avatar-previews/`：三位数字人的静态图。
- `public/vendor/xingyun/`：第三方官方 SDK 构建文件及来源说明。
- `docs/`：技术接口与项目背景文档。部分文档来自早期交接，目录与能力描述以本 README、实现状态说明和当前代码为准。
- `展示素材/`：本次本地浏览器验证时生成的界面截图。

本包是可独立运行的 H5/Node 版本，不包含原始交接包中的微信小程序参考云函数；运行该 H5 不依赖这些参考文件。

## 已实现与边界

已实现：三角色文本对话、后端安全分诊、回复流式显示、星云播报后端回复、播报中断与销毁、未连接静态形象、手机全屏数字人、浏览器本地聊天记录。

数字人仅播报现有后端回复，不调用其独立问答功能。危机回复采用后端固定文案及 12356 援助信息。未实现独立表情/动作映射，也未接入星云自动语音问答。现有录音转写入口另需百度语音配置，不属于无需配置即能运行的能力。聊天数据不提供跨设备云同步。

这是联网演示作品，不是离线数字人软件，也不是 Android APK、iOS 安装包或正式微信小程序包。
